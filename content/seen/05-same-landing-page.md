Tobi 发的是一篇英文长文，题目是 How to Make Claude Design Like a Real Studio。你让 Claude 一分钟做一张落地页，它做得到。每次拿到的几乎是同一张。他把这张脸写得很具体：衬线大标题，其中一个词斜体、用强调色，顶上几颗很小的等宽字，写着类似 now booking，角落里两个城市名，比如 Lisbon / New York。

完整的工作室做法、图和目录，在[那一篇](/read/tobi-claude-studio-design)。这一篇把英文里能单独带走的部分嚼开。不靠那一篇也能读完。

## 同一张脸不是丑，是每个选择都停在默认上

他说，这种页面通常不丑。它只是每个选择都留在最安全的那一档。模型没有东西可看的时候，就会选最安全的字体、最安全的布局、最安全的颜色。安全叠在一起，就是你一眼能认出来的那张脸。

所以他做了一个叫 Construct Design 的库，放在他自己的社区里。数字是他写的：223 件设计，都是活的，都是亲手做的，为了看起来不像生成的。其中 36 个网站首屏，37 个手机应用屏幕，150 个零件，按钮、卡片、滑块、小组件。每一件从想法开始，不从模板开始。他举了三个例子。一个品牌工作室，用一盏灯照出藏在黑色剪影里的彩色照片。一个手机助手，玻璃球在第二声铃响之前就接起来。一份作品集，做成某人笔记本里的一页，宝丽来可以拿起来。

库在 [tobiadonadon.com/projects/construct/design](https://www.tobiadonadon.com/projects/construct/design)。

## 接上之后，它实际做三件事

库配了一个 MCP。接一次就行。他给的那一行是：

`claude mcp add --transport http construct-design "https://www.tobiadonadon.com/api/mcp?key=YOUR_KEY"`

然后你还是用平常的话说：「给我的工作室做首屏，用 Construct Design。」背后三步，他写得很清楚。

`search_designs` 去找想法对得上的那一件。它读的是描述，不只是名字。`design_guide` 去读这类东西该怎么做：过程、字、颜色、布局、动效、最后怎么检查。`get_design` 把真实的代码拿过来，Claude 再写进你的项目。他说这套能在 Claude Code、Claude、Cursor、Codex 和 VS Code 里用。

设计件省的是时间。真正改掉做法的是那份指南。指南来自他的两份设计技能，砍短了，让模型边做边读。

## 不用这个库，也该带走的三句

**第一，先认出四种最常见的生成页面。** 纸感编辑部：衬线标题，一个词斜体并换成强调色，到处是等宽小字，就是开头那张。发布会：黑底，紫光，一张斜着的产品截图。仪表盘：四张指标卡，每张上面一条小折线。暗色开发工具。你的页面如果和其中一种共享了三个特征，退回到想法，不要在这张脸上再改颜色。

**第二，留一个能被人转述给朋友的动作。** 滚动时淡入不算。悬停时抬起一点也不算。要一个朋友会主动描述出来的动作。他说的那些例子就属于这种：灯照出剪影里的照片，球在第二声前接起来，宝丽来可以拿起来。没有这个动作，页面只有信息，没有被人记住的理由。

**第三，做一次替换测试。** 把竞争对手的标志放上去。如果看起来没什么不对，说明你的想法没有进到页面里。页面只是一个能换牌的壳。

他还补了一句，对着模型喊「不要普通」，会得到另一套千篇一律。这次是米白底、巨大标题、编号，页眉上一个钟。那是矫枉过正之后的工作室作品集脸。要的是具体。极简只是到达具体的其中一条路。

## 读完留下的

这篇和这个站直接有关。复利系统里那些网站，就是「给模型一点可看的东西」。Tobi 把这件事做成了能装上的 MCP，还写成了模型边做边读的三条规矩。网站还在复利系统里。装上再跑的那一份，等真的接进日常写页面，再收进工具那一半。

三句里我最信的是第三句。换上别人的标志还成立，就说明这页没有自己的想法。第一句是用来认路的，认完要离开，不要拿来收藏四种脸。第二句最容易被做成又一个默认：每个页面都硬塞一个「能被描述的动画」。动作要是从想法里长出来的。为了有动作而加的动作，就是新的悬停抬起。
