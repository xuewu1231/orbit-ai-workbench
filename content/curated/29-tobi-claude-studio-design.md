现在的 Claude 几乎什么前端页面都能一分钟给你搭出来。你敲一句「帮我的品牌工作室写一个超棒的落地页」，六十秒后就能跑起来。

但致命的问题在于：**你每一次拿到的，几乎都是同一张页面。**

永远是那套衬线大标题；永远把标题中间某一个词改成斜体、涂成橙红色；顶栏永远飘着几颗微小的等宽大写字母写着 `NOW BOOKING`；角落里永远雷打不动地印着一行 `LISBON / NEW YORK`。

> **AI 生成的平庸之作（Slop）通常并不丑——它只是把每一个设计选择，都留在了概率最高的默认安全区里。** 当模型手头没有任何具体参照物可看时，它必然会自动退回最安全的字体、最安全的构图、最安全的配色。

想要打破这个死循环，办法只有一个：**在它写代码之前，先给它真正有灵魂的东西看，并教会它像设计工作室一样思考。**

## 为什么一眼就能认出「这是 AI 写的页面」：四大默认套路脸

Tobi 从自己打磨《App Designer Pro》和《Web Designer Pro》两套设计技能的实战经验里，总结出了当前所有大模型在生成网页时最爱掉进去的**「四个默认套路坑（The 4 Default Looks）」**。哪怕你不用任何第三方组件库，只要把这张表贴在屏幕边对照自查，就能瞬间拦下 80% 的模板味：

:::diagram-four-ai-slop-looks:::

| 套路代号 | 典型视觉症状（命中任意 3 条即刻退回重想） | 为什么模型总爱往这儿掉？ |
| :--- | :--- | :--- |
| **01 · 伪文艺纸刊风**<br>`The Paper Edition` | 衬线大标题里嵌 1 个橙色斜体单词、满屏等宽胶囊标签（`• Q1 BOOKING`）、页脚写着 `LISBON / NEW YORK` | 当提示词出现「品牌、工作室、质感」时的高频训练均值 |
| **02 · 黑紫发光发布页**<br>`The Launch Page` | 纯黑底色、背后一团蓝紫色弥散发光球、首屏一张带透视倾斜的软件截图、渐变流光大字 | SaaS 模板站泛滥导致的「科技感」默认联想 |
| **03 · 四宫格折线看板**<br>`The KPI Dashboard` | 顶上一字排开 4 张等宽指标卡、右上角标着绿字 `+12.8%`、底下配毫无业务焦点的平滑迷你折线 | 后台管理类需求没有信息主次约束时的安全牌 |
| **04 · 暗黑极客工具页**<br>`The Dark Dev Tool` | 炭黑细网格背景、等宽终端字体配闪烁绿光标、满屏无差别的半透明微边框卡片 | 开发者工具与 CLI 产品被过度模仿后的刻板印象 |

更值得警惕的是**「矫枉过正陷阱（The Overcorrection）」**：当你发现页面太俗气，于是气呼呼地对模型喊一句「不要做成通用模板！要极简高级！」，模型马上会整齐划一地跳进第五个坑——米白底色、撑满全屏的巨型无衬线粗黑字、带 `01 / 02` 编号的等宽小标签，外加导航栏右上角放一个实时跳秒的世界时钟。

**记住：极简只是通往好设计的路径之一，你真正该向 AI 索要的不是「极简（Minimal）」，而是「具体而独特（Specific）」。**

## 给模型看真手艺：Construct Design 与它的三步 MCP 工作流

为了让编码 Agent 彻底跳出默认模板池，Tobi 在自己的社区里纯手工打造了一座叫 **Construct Design**（[tobiadonadon.com/projects/construct/design](https://www.tobiadonadon.com/projects/construct/design)）的活体设计库——收录了超过两百多件完全从零构思、绝非套模板生成的真实可交互作品（涵盖网站首屏 Hero、iPhone 原生感界面与精细交互零件）。

这里的每一件作品都不是从「我要排三个框」出发，而是**从一个具体的画面点子（Idea）出发**：
- 一家品牌工作室首屏：鼠标指针化身一束手电筒聚光灯，划过纯黑人物剪影时，才照亮隐藏在剪影内部的鲜活彩色人像；
- 一个电话语音助手卡片：界面中央悬浮一颗通透玻璃光球，在第二声铃响前轻盈浮起接听；
- 一份像私人手账本一样的个人作品集：访客甚至可以用鼠标直接拈起桌上的宝丽来拍立得照片挪动端详。

更巧妙的是他让 Claude、Cursor、Codex 或 VS Code 调用这座设计库的方式——通过一行命令挂载 **MCP 服务**：

```bash
claude mcp add --transport http construct-design "https://www.tobiadonadon.com/api/mcp?key=YOUR_KEY"
```

当你像平时一样对 Claude 说「帮我的工作室搭一个首屏，使用 construct design」时，Agent 在后台并不是简单粗暴地复制粘贴一段死代码，而是严格走完三个递进动作：

:::diagram-construct-mcp-flow:::

1. **`search_designs`（搜背后的点子，而不只是搜名字）**：模型会阅读库里每件作品的设计意图与叙事描述，挑出气质最契合你业务内核的那个原型。
2. **`design_guide`（边写边读设计方法论）**：这一步才是真正脱胎换骨的关键——MCP 会把针对该类型界面的**完整设计准则**（版式推进过程、字阶对比、用色克制比例、动效阻尼手感、自审门禁）实时喂进模型的上下文。
3. **`get_design`（拉取干净源码并融入你的项目）**：最后才把真实手写的 React 组件拉下来，自动替换对齐你工程里现有的主题色板、品牌词与光线参数，干净利落地落成一个文件。

## 就算不装任何库，今天也能直接拿走的三条工作室铁律

Tobi 在文末坦诚地说：**现成的设计组件只是帮你省时间，真正改变模型审美水平的是那份精简版设计指南（Design Guide）。** 哪怕你完全不用他的库，只要每次做页面时守住下面这三条硬准则，出品水准也会立刻拉开代差：

### 1. 先做「套路查重」：命中三项立刻推倒重来
页面第一版跑出来后，先对照上面的「四大默认套路脸」逐项打勾。如果你的页面和其中任意一张脸撞了三个以上特征，不要在上面修修补补调间距——说明你还没给它真正的视觉主意，回到起点重新想画面。

### 2. 全页只挑一个「能让朋友开口描述的标志动作（Signature Move）」
问自己一个问题：别人逛完你的网站关掉标签页后，跟朋友提起它时会怎么形容？
**注意：「滚动时文字淡入上浮（Fade-up on scroll）」根本不算数，「鼠标悬停卡片往上抬 4 像素（Hover lift）」也不算数。** 真正的标志动作是一束能照亮剪影的手电光、是一排点击会物理变形的矢量键帽、是一张能亲手拖开对比前后差距的滑杆——整页克制留白，只把这一个核心交互做到让人过目不忘。

### 3. 终极灵魂拷问：做一次「竞品换标测试（The Swap Test）」
把你页面左上角的品牌名字和 Logo 抠掉，直接换上你头号竞争对手的 Logo。
**如果换完之后整张页面看起来依然严丝合缝、毫无违和感，那就说明属于你自己的产品灵魂根本没有写进这张页面里。** 好的设计一定长在产品独有的工作流与性格之上，谁也偷不走、谁也换不了标。
