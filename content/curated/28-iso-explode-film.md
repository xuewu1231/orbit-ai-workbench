最近，AI 写代码做视频，是真的火。

这类视频不用 AI 扩散模型生成，而是让大模型写一段代码，代码跑完，出来就是一条成片。

我这段时间刷到好多案例。

产品发布片，品牌 Logo，App 界面动效，信息图，金融数据，数学和历史科普，3D 场景复原，甚至一整支 MV。

能干的事，比我想象的多太多了。

很多朋友可能会觉得，这不就是 AI 做视频嘛，Seedance、可灵不早就能做了。

其实差别还挺大的。

AI 生视频模型擅长人物和风景，像实拍，可一碰到文字、图表和精密结构就容易乱，还贵。

AI 写代码做视频正好反过来。每个细节都是算出来的，又准又便宜，哪一帧不满意，改一行代码就行。

这段时间，我花了很多时间研究 AI 写代码做视频，踩了不少坑，也攒了一些小心得，想一个一个端出来分享给大家。

先给大家看一条我最近做的片子。从建模到动画到渲染，全是 AI 写的代码。

这种片子，以前找团队做，30 秒要好几万。我花了一个上午，十几块钱就做出来了。

这套做法我整理成了一个 Skill，叫「等轴爆炸大片」（`iso-explode-film`），已经在 GitHub 开源，链接放在评论区。

把链接丢给 DeepSeek、豆包、Qwen 这些国产模型，Agent 会自己装好，照着做出同样风格的片子。我还让 DeepSeek 完整做了一遍，结果放在最后。

下面一步一步讲。

---

## 从 GitHub 爆火的 Anatomy Skill 说起

故事要从一个在 GitHub 上爆火的 Skill 说起。

Anatomy Skill，上线 2 周，GitHub 上斩获 2.1 万星。

它的原理是，让 AI 用代码把一台机器，画成等轴测的交互图，在网页里可以拖动旋转、点击操作，还能把整台机器拆开来看。

![Anatomy Skill 网页等轴测交互拆解动图演示](/figures/iso-explode-film/wx_01.gif)

Anatomy 的审美非常高级。白底，细线，每个零件只用几档明暗区分，克制、干净，像一本印刷精良的技术手册。

![Anatomy 白底细线、技术手册质感的等轴测视觉风格](/figures/iso-explode-film/wx_02.png)

这种画法叫等轴测，游戏「纪念碑谷」就是这种视角。没有近大远小的透视，图上的比例和实物一致。机械制图、装配爆炸图、产品说明书都常用它。

![无近大远小透视的等轴测机械结构图例](/figures/iso-explode-film/wx_03.png)

但这个 Skill 也有短板。

它擅长的是轻量的交互，零件拆开也只是往上抬起、错开一点，做不出工业爆炸图里那种几百个零件层层炸开、镜头跟着推拉的大片效果。

没过多久，又有人在 Anatomy 的基础上做了一个 Skill，叫 Anatomy Reveal，让等轴图动了起来。

我也照着玩了一下，做了一台面包机。

这两个 Skill 我都很喜欢。Anatomy 审美好，适合轻量的网页交互；Anatomy Reveal 更进一步，能出一条拆解短片。

但用多了，我发现它们有两个不足。

一是不真实。零件是 AI 凭印象编的，尺寸是估的，螺丝几颗、内部怎么排布，都对不上。

二是不炸裂。拆开也就几十个零件，稍微抬起、错开，没有层层炸开的那种冲击力。

我就在想，能不能用等轴测的方式，还原真实的机械和产品？

这种需求还挺大的。

给客户讲清产品内部结构，一步步演示维修和组装，给孩子讲机器怎么工作，给测评和科普配拆解画面，甚至直接做成产品广告片。

我找了一圈，没有现成的 Skill 能干这件事。

于是，我打算自己开发一个 Skill，做真实产品的等轴风格爆炸动画。

---

## 踩坑实录：从 856 个无名零件到大片质感

第一步，必须得找一个有真实工程图纸的产品。

真正开源工程图纸的产品太少了，在网上找了半天，最后选了 Keychron 的 Q1 HE 8K 键盘。

Keychron 是个大善人，把一百多款键盘的 CAD 图纸都免费放到了 GitHub 上。

打开图纸，我靠，856 个零件。

![Keychron Q1 HE 8K 开源 CAD 工程图纸中的 856 个零件](/figures/iso-explode-film/wx_04.png)

更要命的是，这 856 个零件，没有一个有名字。

我只能把它们交给 Claude Opus 5.5，一块一块辨认。花了一个多小时，终于把外壳、定位板、电路板、轴体、键帽，逐个上了号。

然后就是这个 Skill 最核心的一步。

Opus 5.5 照着图纸，把每个零件重新画一遍。尺寸、位置、上下叠放的关系，全用图纸里的真实数据，形状换成等轴测风格的干净几何体。

![照着真实图纸尺寸重绘的等轴测干净几何零件](/figures/iso-explode-film/wx_05.png)

重画完，我以为可以做动效了。

可是键盘模型一加载，内存一路涨，画面崩了。

零件太多，太碎。这下只能做减法，画面里看不见的，统统不要，长得一样的，编成一组。

![删减不可见零件并合并同类零件组后的清爽层级](/figures/iso-explode-film/wx_06.png)

键盘模型一下轻了。更没想到的是，画面也跟着干净了，层次一眼就能看清。

这条，后来写进了 Skill。

键盘模型终于能动了。

刚松一口气，画面开始一闪一闪。

几百个零件挤在一起，互相遮挡，只要算错一帧，零件就在前后之间来回跳。

等轴测好看，全靠一个干净，这一闪，什么都没了。

折腾了好几轮才跑通。

Skill 里定下，片子的每个动作都是提前设计好的，那每一帧谁在前、谁在后，也可以提前算好。再加一道逐帧检查，闪一帧都不放过。

![预计算前后遮挡顺序并加入逐帧闪烁检查](/figures/iso-explode-film/wx_07.png)

接下来是我最期待的一步，炸开。

零件一飞出去，又翻车了。路线一交叉，零件互相穿来穿去，乱成一团。

于是，我又在 Skill 里加了条规矩。先分层，再散开，合回去时，先收小零件，再合大的层。

规矩一立，爆炸从一团乱飞，变成了一层一层地打开。有秩序，也有了节奏。

![先分层再散开、先收小件再合大层的有序爆炸轨迹](/figures/iso-explode-film/wx_08.png)

到这里，画面干净了，也不穿模了。

可我看着成片，总觉得哪里不对。

太平了。

等轴测没有透视，镜头一动，像在看一张会动的图纸。好看，但不像大片。

最后这一下，我在干净的等轴画面上，又套了一层透视。镜头终于能推、能拉、能甩了。甩的时候带上动态模糊，每一次切换，都踩在音乐的节拍上。

![叠加镜头透视推拉、甩镜动态模糊与音乐节拍卡点](/figures/iso-explode-film/wx_09.png)

大片的味道，终于出来了。

## 封装成 Skill：9 步流程与 4 条硬规则

每踩一个坑，我就把解决办法写进去，最后攒成了一个 Skill，叫「等轴爆炸大片」。

Skill 并不复杂，整个流程分 9 步，只有两步需要人拍板。

![iso-explode-film 九步工作流示意（仅两步需人工拍板）](/figures/iso-explode-film/wx_10.png)

:::diagram-code-video-pipeline:::

简单说，就是先把产品拆成几百个真实的几何零件，再按分镜让这些零件一帧一帧动起来，最后由程序把每一帧合成成片。AI 写的是零件和镜头，画面是算出来的，所以每一帧都能精确改。

为了让 AI 每次都做对，Skill 里定了几条硬规则，每一条都是一个坑换来的：

- **几何即一切。** 画面里只有代码搭的零件，不贴图，不用照片，连面板上的印刷字都画在零件表面。
- **真实尺寸。** 零件数、层级、开合方式都照真东西来，细节靠真实零件撑，不靠想象往上堆。
- **一镜到底。** 换镜头靠 0.25 秒的甩镜，停留时镜头也在缓缓漂，只有最后半秒是静止的。
- **风格确定。** 机位、橙黑两套配色、字体、字卡位置都写死在 Skill 里，AI 不用每次重新发挥审美。

它不挑输入。有 CAD 图纸最好，网格模型、图纸、几张照片也能做，只是精度往下降。

也不挑产品，我拿一个充电宝从头跑了一遍，照样能出片。

![跨产品验证：用同一套 Skill 跑出的充电宝等轴爆炸动画](/figures/iso-explode-film/wx_11.png)

## 国产模型实测与导演思维

最关键的一点，这个 Skill 不挑模型，DeepSeek、豆包、Qwen 这些国产模型都能用。

我拿 DeepSeek 4.1 Flash 1017 试了一遍，给它同一份 CAD 图，让它照着 Skill 自己做。

429 个零件，尺寸误差不到 0.01 毫米。900 帧零穿模。节奏误差最大 0.067 秒。字卡位置误差不到 1 个像素。

花了多少钱？**14 块。**

同样的工作量，Claude Opus 5.5 大约 106 美元。

做完这 Skill，我最大的一个体会是，用代码做视频，现在一线的模型基本都能做。**真正拉开差距的是审美，以及有没有导演思维。**

DeepSeek 这次能做到八九成，分几层、怎么炸、镜头停在哪、哪一秒卡点，这些判断是我写进 Skill 里交给它的。

所以我觉得，模型越强，对用它的人要求反而越高。

人要负责给方向：什么样的画面好看，节奏怎么排，观众看到哪一秒会想多看一眼。

这个 Skill 算是我的一次尝试，试着把自己对好看的一点理解写下来，交给模型去执行。

我的审美也不见得多好，片子里还有不少能改的地方，欢迎大家指出来。

「等轴爆炸大片」（`iso-explode-film`）已经在 GitHub 开源，下载链接在评论区。

用法很简单。把这个链接丢给你的 Agent（豆包工作、千问办公、Workbuddy、Claude Code、Codex 都行），说一句「装上这个 Skill，用它把我的产品做成一条 30 秒的等轴爆炸大片」，它会自己装好开工。手上有 CAD 图纸最好，没有的话，网格模型、图纸、几张照片也能做。

做出来的片子欢迎发我看看。

如果大家喜欢，后面我会接着做更多用代码写视频的 Skill，比如更有立体感的 3D 风格。

你最想用代码做一条什么样的视频？想看哪种风格的 Skill？评论区告诉我，呼声高的我先做。
