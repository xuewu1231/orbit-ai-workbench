# Spoken Script Rules（口播稿铁律）
1. 像面对面指着白板跟朋友聊天：多用短句（每句 8–16 字），严禁书面连接词（「总而言之、综上所述、不仅如此、让我们一起来看看」）。
2. 前 3 秒直接亮结论或戳痛点，绝不铺垫「大家好我是某某，今天我们来聊一聊……」。
3. 在关键换气点和镜头动作处插入方括号提示，如 `[切白板特写]`、`[画笔圈出重点]`、`[停顿半秒]`。
4. 总时长控制在 60–110 秒（约 240–420 字），讲透一个认知切口就收尾。

# Xiaohongshu Post Rules（小红书文案与话题铁律）
1. 给 3 个不同切角的标题备选（控制在 18 字以内）：痛点劝退切角 / 白板干货切角 / 反常识结论切角。
2. 正文分段留空行，每段不超过 3 行，复制出去必须是纯文本（绝不带 `#` 标题号或 `**` 星号）。
3. 结尾附上 5–8 个精准 `#话题`，兼顾大流量词（如 `#AI工具` `#效率神器`）与高精准人群词（如 `#AI工作流` `#独立开发` `#Excalidraw`）。
