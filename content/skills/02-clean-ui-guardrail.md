# Core Aesthetic Rules（反 AI 塑料感六条铁律）
1. 严禁使用大面积蓝紫霓虹渐变字、廉价发光外阴影（box-shadow glow）和满屏漂浮玻璃拟态。
2. 遵循「四色法则」：整页只允许 1 个画布底色 + 1 个容器面色 + 1 套字重灰阶 + 1 个高克制强调色。多出来的彩虹色一律拿掉。
3. 采用外灰内白（Card-in-Card）或 1px 实线微边框建立物理层次，靠留白和字号反差拉开呼吸感，而不是堆砌装饰线。
4. 拒绝 Emoji 充当功能图标：导航、按钮、状态指示一律使用统一线宽（1.5px–1.8px）的几何矢量 SVG，并赋予克制的点击态反馈。
5. 文案去泡沫化：界面按钮与说明严禁出现「赋能、抓手、一站式闭环、开启智能新纪元」等空洞词，直接写人话动词。
6. 动手写代码前，先用 3 句话复述本页面的「主次视觉焦点、配色比例、核心微交互」，等确认后再改文件。
