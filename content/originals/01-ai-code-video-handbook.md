做产品演示片、功能发布视频或硬核知识可视化时，很多人都有过同一种挫败感：明明用了当下最聪明的编程大模型，对它说「帮我用代码写一段超帅的产品介绍视频」，结果跑出来的画面却像上世纪的死板 PPT——字糊在一团、匀速平移毫无质感、切镜生硬得像断电，甚至导出 MP4 时还疯狂闪屏掉帧。

原因很简单：**大模型懂怎么写 React 和 SVG 语法，但它默认没有「导演分镜感」和「帧级确定性工程约束」。**

想标准、稳定地做出真正有工作室水准的代码视频，光等模型升级没用，手头必须备齐四样武器：**一套经过验证的视觉效果库、一套虚拟摄像机与切镜节奏法则、一本说准一个词顶一百句废话的术语词典，以及一份锁死工程下限的标准提示词模板。**

## 一、开场前 3 秒与「真实动态入镜」核心效果库

为什么我们要大费周章用代码去算视频，而不是拿录屏软件手剪或者丢给黑盒文生视频？因为代码视频能把**「100% 真实的软件动态交互」以无限分辨率直接嵌进镜头里**，而且改一句文案、换一套配色，只需一秒钟重新编译整支 60fps 成片。

根据我们之前反复推演过的场景，最抓人的视觉效果可以清晰归为**「前 3 秒黄金开场 4 式」**与**「正片真实动态 5 式」**：

:::diagram-code-video-effects:::

### A. 前 3 秒黄金开场 4 式（决定观众划不划走）

1. **重字砸屏卡点（Kinetic Stomp / Beat-Sync Typography）**
   - **画面表现**：纯色干净画布上，不说废话，痛点短句按词语切碎，配合鼓点每 12–18 帧重重砸出一组高字重关键词（微带 `scale: 1.18 → 1.0` 的物理回弹），最后在核心痛点词底下用荧光笔色条（Highlight Sweep）横扫划出重点。
   - **最适合**：观点暴击型知识科普、戳穿行业痛点的功能发布片开头。
2. **前后反差滑杆擦除（Split-Screen Wipe Reveal）**
   - **画面表现**：第 1 秒先展示灰暗杂乱、报错频出的旧工作流画面（打上红色 `✕ 旧做法` 角标）；第 1.5 秒一道发光分割线从左向右极速横扫（`clip-path` 动态裁切），瞬间揭晓干净克制的新界面。
   - **最适合**：工具提效对比、UI 改版前后反差、自动化替代手工搬砖类选题。
3. **实时指令敲击唤醒（Live Prompt / Terminal Wakeup）**
   - **画面表现**：屏幕中央只有一个极简输入框或暗黑终端，光标高频闪烁两次后，高速敲入一句自然语言指令；按下回车的瞬间，输入框利用共享圆角变形（Morph）直接炸开扩展成完整的产品工作台。
   - **最适合**：AI Agent 产品、CLI 开发工具、一键生成类平台的旗舰演示。
4. **暗角聚光灯特写（Vignette Spotlight Callout）**
   - **画面表现**：先把完整复杂界面铺在底层，第 10 帧迅速把四周压暗 70% 并加轻微高斯模糊，只留一束圆角聚光灯精准框住最扎心的那个报错数字或核心按钮，同时摄像机同步推进 `1.6x`。
   - **最适合**：复杂 B 端后台亮点拆解、Bug 根因复盘、产品微交互细节炫技。

### B. 把「真实动态」放进视频的 5 大核心杀手锏

传统录屏一旦放大就会糊成马赛克，而且真人在录屏时鼠标难免手抖、停顿不均、打字出错。用代码把「真实动态」写进视频帧，核心就是下面这五招：

- **① 真实前端组件矢量直出（Live Component Mounting）**：直接把项目里的真实卡片、按钮、代码块、流式聊天气泡挂进视频画布。哪怕虚拟镜头推进到 `2.5x` 超近景特写，每一个圆角、1px 微边框和字体笔画依然是 4K 矢量级锐利度。
- **② 编排式拟真光标与微反馈（Choreographed Cursor & Click Ripple）**：用三次贝塞尔曲线算好一颗高精度矢量光标的运动路径——从右下角优雅弧线滑入 → 悬停目标按钮触发高亮 → 停顿 6 帧 → 按钮执行 `scale(0.95)` 按下回弹并炸开一圈半透明扩散波纹 → 按钮图标由 `✦` 丝滑变形为绿色 `✓`。零手抖，节奏爽感拉满。
- **③ 数据里程表跳字与弹簧图表（Odometer Counter & Spring Charts）**：讲到「提速 8.5 倍」「准确率 98.2%」时，绝不放一张死图表——数字按缓动曲线飞速滚动定格，对比柱状图带着物理弹性依次拔起，架构图里的连接虚线沿着 `stroke-dashoffset` 跑起脉冲电流。
- **④ 3D 空间透视叠卡与等轴拆解（3D Perspective & Isometric Explode）**：前两秒看似普通的二维网页卡片，随着镜头一转进入 `perspective(1200px) rotateX(18deg) rotateY(-16deg)` 的三维舞台，Z 轴上下拉开真实投影，把「表层 UI → 中间状态层 → 底层数据流」像三明治一样拆开给观众看。
- **⑤ 逐词跟随胶囊字幕（Word-Level Kinetic Captions）**：不再用呆板的底部死字幕，而是让底色高亮小胶囊像卡拉 OK 游标一样，踩着口播每个重音词平滑滑过去，重点词自动放大 `1.12x` 变色。

## 二、切镜的节奏与真实感运镜：怎么告别「死板 PPT 味」

同样是把卡片摆在屏幕上，为什么高手做的像 Apple 发布会宣传片，新手做的像乡镇企业幻灯片？**差距全在「虚拟摄像机运镜（Camera Choreography）」和「剪辑切镜节奏（Cutting Rhythm）」这两件事上。**

:::diagram-camera-choreography:::

### 1. 核心思维转换：动机位，不要乱动满屏零件

新手写动画最爱犯的错，是让标题从左边飞进来、图片从右边飞进来、按钮从底下弹上来——满屏零件各飞各的，看得人眼花缭乱。

专业导演的做法是：**页面里的组件安安静静待在它该在的栅格位置上，我们在最外层套一个 `<CameraRig>`（虚拟摄像机容器），通过改变摄像机的焦距与机位来引导观众视线！**

### 2. 六种必收的「真实感摄像机运镜」

| 运镜名称（中英术语） | 画面运动轨迹与代码本质 | 什么时候用它最出彩？ |
| :--- | :--- | :--- |
| **推镜聚焦**<br>`Push-in / Macro Focus` | 画布整体围绕目标坐标从 `scale(1)` 推进至 `1.75`，同时配合 `rotateX(5deg)` 微倾与背景轻度模糊 | 口播讲到「注意看右上角这个开关」或展示局部微交互手感时 |
| **拉镜揭晓全局**<br>`Pull-back Reveal` | 开场先锁在 `scale(2.0)` 的局部小卡片里讲单点，转折句一到，平滑拉回 `scale(1.0)` 露出整座工作台全貌 | 讲生态全景、多模块协同架构、「它不只是一个按钮，而是一整套系统」 |
| **极速甩镜转场**<br>`Whip Pan + Motion Blur` | 在 12–16 帧（约 0.25 秒）内沿 X 或 Y 轴高速位移一整屏，并在速度峰值帧叠加水平方向模糊（`blur`） | 章节切换、从「痛点篇」干脆利落地切入「解法篇」，踩鼓点极帅 |
| **滑轨跟随平移**<br>`Tracking / Follow Shot` | 摄像机中心点绑定虚拟光标或流程箭头的实时坐标，带 8 帧阻尼滞后（Lag）平滑跟拍 | 演示跨步骤流水线（Step 1 → Step 2 → Step 3）或跟随鼠标填表点击 |
| **匹配变形剪辑**<br>`Match Cut / Shared Morph` | 上一幕居中的胶囊搜索框，在 18 帧内直接改宽高圆角无缝撑大，变成下一幕的主窗口外框 | 让前后两幕产生极丝滑的「一镜到底」高级连接感，消除硬切割裂 |
| **悬浮微呼吸**<br>`Ambient Camera Drift` | 在停留阅读的 2 秒内，给机位叠加极克制的正弦微漂移（`±3px` 位移 + `±0.3deg` 浮动），最后半秒定格 | 彻底杀掉纯静态画面的「死图感」，让整个三维舞台像真机手持实拍 |

### 3. 切镜与物理弹簧的三条黄金铁律

1. **「3 秒视觉换气」铁律（60fps 下每 120–180 帧一次变化）**：人眼盯着完全静止的数字屏幕超过 3.5 秒注意力就会断崖下跌。不需要每 3 秒换掉整个大背景——第 0 秒卡片弹入、第 1.5 秒光标滑入点击、第 2.8 秒摄像机微推 `1.3x` 高亮结果，这种「小动作接力」就能让节奏紧凑却不累。
2. **彻底封杀 `linear` 匀速运动，全员改用物理弹簧（Spring Physics）**：现实世界里没有任何有质量的物体是匀速启动又瞬间急停的。不同重量的元素必须配不同的弹簧阻尼：
   - **重型摄像机推拉（沉稳不晕）**：`stiffness: 120, damping: 24, mass: 1.1`（平滑到位，零多余晃动）
   - **UI 卡片与弹窗入场（清脆利落）**：`stiffness: 210, damping: 20, mass: 0.9`（带约 3% 的微妙呼吸回弹）
   - **按钮点击与徽章跳出（轻快弹手）**：`stiffness: 320, damping: 16, mass: 0.7`（干脆有脆感）
   - **多列表错峰阶梯（Stagger Delay）**：并排出现 3–4 张卡片或列表项时，每项依次错开 `4 帧`（约 66ms），像多米诺骨牌一样顺滑铺开。
3. **声画前导法则（J-Cut & Accent Lock）**：转场的风声（Whoosh）或按键咔哒声要比画面动作最高速帧**提前 3～4 帧**切入；大字砸屏定格的那一帧，必须严丝合缝卡在口播重音字落下的瞬间。

### 2. 12 个「说准一个词顶一百句解释」的核心术语词典

- **`Sequence`（帧序列片段）**：按精确帧号（`from` 起始帧、`durationInFrames` 持续帧数）切分每一幕独立镜头，互不污染时间轴。
- **`Deterministic Frame`（纯帧号确定性渲染）**：视频每一帧的样式必须完全由 `f(frame)` 纯函数算出，任意拖到第 237 帧永远长一模一样。
- **`Camera Rig`（虚拟摄像机架）**：包裹整个场景的外层变换容器，统一负责推拉摇移与三维透视倾角。
- **`Spring Config`（物理弹簧曲线）**：由刚度 `stiffness`、阻尼 `damping`、质量 `mass` 三参数决定的自然运动物理模型。
- **`Extrapolate Clamp`（边界钳制锁定）**：插值计算到达目标帧后死死锁住终点值（`extrapolateLeft/Right: "clamp"`），防止数值继续无限飞出屏幕。
- **`Stagger`（错峰延迟阶梯）**：一组子元素入场时按索引 `index * 4` 帧依次错开启动，营造顺滑韵律。
- **`Kinetic Typography`（动力学字体排印）**：文字按行、按词或按字符拆开，配合字重跳变、遮罩上浮（Mask Reveal）与高亮底条做出的节奏字幕。
- **`Match Cut`（共享几何匹配剪辑）**：利用前后两幕相似的几何外框无缝变形过渡，替代生硬切黑屏。
- **`Whip Pan`（急速甩镜）**：短时间内大跨度横纵平移镜头并伴随方向性模糊的高能转场。
- **`Vignette & Spotlight`（暗角压暗与聚光）**：压低非核心背景区域亮度对比度，强行收束观众视觉焦点。
- **`Stroke-Dashoffset Draw`（矢量路径生长）**：通过动态改变 SVG 路径虚线偏移量，实现手绘圈重点、流程图连线自己画出来的效果。
- **`Safe Area`（画幅安全保护区）**：四周预留 `8%–12%`（竖屏底部预留 `18%`）绝不放关键文字，防止被平台点赞栏和标题遮挡。

## 四、如何标准化稳定做出好片？（五条工程红线 + 三套标准 Prompt）

把模型换到最强之后，想要**每一次出片都保持 85 分以上的稳定工业水准**，核心秘诀在于：**不要一上来就让 AI 直接写几百行视频代码，而是按「锁常量 → 审分镜 → 套红线写码 → 抽静帧微调」四步走，并把下面五条工程红线死死焊进提示词里。**

:::diagram-video-standard-sop:::

### AI 写代码视频必挂的「五条工程死红线」

1. **红线一：严禁使用 CSS `transition`、`@keyframes`、`setTimeout` 与 `Math.random()`！**
   这是 99% 新手用 AI 写 Remotion / Canvas 视频导出必闪屏的元凶。并发渲染器是把第 10 帧、第 50 帧分给不同线程同时截图的，CSS 过渡根本来不及触发。**一切位移、透明度、缩放、颜色变化必须 100% 由当前帧号 `frame` 纯函数决定；需要随机粒子必须用固定种子（Deterministic Seed）。**
2. **红线二：所有 `interpolate()` 必须默认锁死 `extrapolateLeft: "clamp", extrapolateRight: "clamp"`！**
   漏写钳制会导致第 30 帧之后卡片继续往天上飞、或者透明度算出负数报错。
3. **红线三：先单独建一个 `theme.ts` 锁死四色、字阶与三套标准弹簧参数！**
   绝不允许 AI 在每个子组件里随手乱写 `#ff00ff` 或拍脑袋编阻尼数字，全片共享同一套色彩与物理惯性。
4. **红线四：同屏最多不超过 2 个运动焦点，字号放大至普通网页的 1.6 倍！**
   视频是走马观花看的，不是凑在屏幕前细读的网页。卡片里绝不塞大段说明文，主标题 `56px–84px`，卡片标签 `24px–32px`，四周严格留足 10% 安全边距。
5. **红线五：先输出纯文本「帧级导演分镜表」由人拍板，确认后再生成组件代码！**

### 直接复制给 AI 用的三套标准纯文本提示词

下面三套指令已经把上述术语、运镜和工程红线全部打包好，需要做视频时直接点右上角复制粘贴给 Claude Code、Cursor 或 Gemini 即可：

#### 标准指令 01 · 口播稿/文章转「帧级导演分镜单」（动手写代码前必跑）

```text
任务：我要用代码制作一支 60fps 的高质感短片（画幅：1920x1080 横屏 / 或改为 1080x1920 竖屏）。请先不要写代码，先把下面这段内容拆解成一份专业的「帧级导演分镜单」。

视觉主题：采用 Keynote 纯白精密风（画布 #F5F5F7，卡片 #FFFFFF，主字 #0A0A0B，唯一强调色 #2563EB；严禁蓝紫霓虹渐变与 Emoji 图标）。

请你按以下格式输出每一幕（每幕控制在 2.5–4 秒，即 150–240 帧）：
1. 幕号与帧区间（例如 Scene 01 · 0–150 帧）
2. 对应口播台词与重音卡点词
3. 核心视觉主体（从「重字砸屏卡点 / 前后反差滑杆 / 真实 UI 组件挂载 / 拟真光标点击 / 弹簧数据跳表 / 3D 透视分层」中选择，同屏不超过 2 个焦点，卡片文字不超过 15 字）
4. 虚拟摄像机运镜（明确标出 Push-in 推镜特写、Pull-back 拉镜全局、Whip Pan 甩镜转场或 Match Cut 匹配变形）

输出完分镜单后停下来等我拍板，确认无误后再进入编码阶段。

我的原始内容如下：
[在这里粘贴你的口播稿、产品卖点或文章摘要]
```

#### 标准指令 02 · 代码视频生成「工程硬护栏」（让 AI 写 Remotion / React 视频代码时挂载）

```text
请严格按照我们刚刚确认的分镜单编写完整可运行的视频组件代码，并无条件遵守以下 6 条视频工程铁律：

1. 纯帧号确定性渲染（最高红线）：严禁使用任何 CSS transition、CSS animation、requestAnimationFrame、setTimeout 或无种子的 Math.random()。所有位置、缩放、旋转、透明度、进度条与数字跳变，必须 100% 基于当前帧 frame 通过 spring() 或 interpolate() 计算得出。
2. 边界钳制：所有 interpolate 调用必须显式包含 extrapolateLeft: "clamp" 与 extrapolateRight: "clamp"，防止元素越界飞出。
3. 统一主题与物理预设：先在顶层定义 THEME 常量（四色色板、圆角、阴影）和 3 套标准弹簧配置——CAMERA_SPRING（damping: 26, stiffness: 120 沉稳运镜）、CARD_SPRING（damping: 20, stiffness: 210 清脆入场）、TAP_SPRING（damping: 16, stiffness: 320 点击微弹）。严禁使用呆板的线性匀速位移。
4. 虚拟摄像机架构：实现一个可复用的 CameraRig 外层容器，统一控制画面的 scale 推拉、translateX/Y 摇移与微幅呼吸漂移，不要让满屏子组件各自乱飞。
5. 视频级大字号与安全区：四周必须保留至少 10% 的 Safe Area 内边距；正文字号与行距比常规网页放大 1.5 倍以上，数字统一开启 tabular-nums 等宽对齐；功能图标一律使用干净的几何矢量 SVG。
6. 模块化拆分：每一幕封装为独立的 Scene_01、Scene_02 子组件，在主时间轴里用 Sequence 清晰串联，方便我单独微调某一幕的帧长与台词。
```

#### 标准指令 03 · 单镜头质感精修（「画面太干瘪像 PPT」时的急救调优指令）

```text
当前这一幕跑出来的视觉效果偏平淡，有点像静态 PPT 平移。请只针对这一幕做以下三处「导演级质感升级」，保持其余逻辑不变：

1. 增加真实动态交互细节：不要直接把最终状态摆在屏幕上——前 25 帧先让主卡片带 CARD_SPRING 阻尼浮现；第 35–65 帧引入一颗贝塞尔曲线轨迹的矢量光标滑向核心按钮，执行 scale(0.95) 按下回弹并触发状态切换（或让关键指标从 0 滚动跳变到目标值）。
2. 补齐摄像机主次聚焦（Camera Push-in + Vignette）：当动作发生时，让外层 CameraRig 从 scale(1.0) 平滑推进到 scale(1.45) 聚焦在操作区域，同时非焦点背景卡片透明度轻微压低至 0.55，替观众锁死视线。
3. 错峰节奏（Stagger）：并排的子元素入场时每项错开 4 帧（index * 4），并在本幕最后 15 帧做好衔接下一幕的收束过渡。
```
