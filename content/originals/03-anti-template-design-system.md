当代码实现门槛被拉平之后，**审美与质感（Taste & Craft）正在成为产品公司最直观的第一道护城河**。

但如果你直接对大模型说“帮我做一个现代、高级的产品官网”，十有八九会得到同一个模子刻出来的页面：纯黑或纯白背景、刺眼的蓝紫色渐变标题、满屏一模一样的圆角发光卡片，以及毫无呼吸感的居中大字。

这种“AI 默认模板感”会在三秒钟内摧毁用户对你们产品专业度的信任。

## 一、诊断“塑料感”的三个病灶

为什么模型默认写出来的前端缺乏高级感？因为它的训练均值里充斥着大量速成落地页模板：

1. **色彩过饱和且缺乏温度**：滥用纯 `#000000` 或 `#FFFFFF` 搭配高饱和霓虹色，缺少自然材质（宣纸、石材、松烟墨）里的微妙暖灰过渡。
2. **侧边栏与装饰噪音过多**：生怕页面空，左边塞目录树、右边塞大纲、背景塞发光球，反而把真正重要的内容挤压得局促不堪。
3. **缺少专属的“图形母题（Visual Motif）”**：没有统一的装帧符号（如编号印章、微缩书封、等宽元数据标尺），看完就忘。

## 二、建立独家视觉母语的四步约束法

我们在 `@folio/skill-editorial-ui` 中固化了一套硬性设计工程流程，彻底禁止模型自由发挥俗套样式：

1. **先锁死语义化 CSS 变量表**：全站正文、次要说明、描边分割线、画框底色全部收敛到不超过 8 个经过严格对比度校准的变量，强调色只保留一主一辅（如朱砂红配松烟绿）。
2. **用“单栏画框 + 留白阶梯”替代网格堆砌**：参考实体精装书的版心比例，把阅读行宽严格控制在每行 36–42 个汉字，行高保持在 `1.8–1.9`，给眼睛留出呼吸余地。
3. **三稿单文件盲选机制**：正式写业务组件前，先让 Agent 在独立 HTML 里分别按“瑞士建筑网格”、“温暖人文杂志”、“极简精密仪器”出三版迥异的小样，真人拍板定调后再拆解工程化。
4. **用代码化 SVG 统一信息图美学**：拒绝在一篇严肃文章里混杂五种不同画风的网图，所有流程图与架构图全部复用同一套圆角、字号与配色规范的定制 SVG。
