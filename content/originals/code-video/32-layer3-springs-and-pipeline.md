## 一、动画手感调校：为什么不能用匀速，弹簧到底怎么选？

在真实世界里，你把一部手机推到桌子另一头，或者伸手按下开关，物体的运动永远有**加速、阻力和惯性缓冲**——绝没有任何东西是“0 秒突然匀速走，到终点又 0 秒突然钉死”的。

但如果你不提前规定，AI 写代码最爱偷懒用的就是死板的匀速直线公式（`linear`）。哪怕你的配色再好看，只要一动起来是匀速的，整支片子瞬间就会透出一股廉价课件味。

点击下方实测台右上角的 **「触发四轨同步弹射」**（强烈建议再点一下 **`速度 0.3x`** 慢动作看），一眼就能看懂匀速和三档物理弹簧的区别：

:::live-springs-compare:::

### 1. 不用自己算物理公式：直接按用途分三档弹簧

你不需要自己去调复杂的刚度（`stiffness`，数字越大冲得越猛）和阻尼（`damping`，数字越小刹不住车来回弹，数字越大稳稳停住），在项目里直接按下面这三个角色对号入座就行：

- **第一档 · 摄像机推拉专用（`CAMERA_SPRING`）**：刚度 `150` / 阻尼 `26`。特点是**沉稳顺滑、到终点绝不来回晃**。因为整个屏幕都在动，如果摄像机到了终点还弹两下，观众看半分钟就会头晕。
- **第二档 · 大字与卡片出场专用（`CARD_SPRING`）**：刚度 `220` / 阻尼 `19`。特点是**干脆利落，停稳瞬间有极其轻微的一丝丝呼吸缓冲**，看着最舒服自然。
- **第三档 · 盖印章 / 按钮点击 / 数字跳变专用（`TAP_SPRING`）**：刚度 `340` / 阻尼 `15`，再配合起跳前微蹲蓄力。特点是**力量感极强、脆弹清亮**，专门用在打重音的地方。

### 2. 直接放进项目的纯时间动画工具函数（可复制进 `src/motion.js`）

为了让 AI 100% 算出不闪屏的纯时间弹簧，你可以直接把下面这 25 行轻量数学工具塞进项目的 `src/motion.js` 里供全片调用：

```javascript
// 1. 强制把进度锁死在 [0, 1] 之间，防止动画超时后元素飞出屏幕
export function clamp(val, min = 0, max = 1) {
  return Math.max(min, Math.min(max, val));
}

// 2. 纯时间解析解弹簧函数：给定经过的秒数 elapsed，100% 确定性算出当前位置 (0 -> 1)
export function springAt(elapsed, { stiffness = 220, damping = 19, mass = 1 } = {}) {
  if (elapsed <= 0) return 0;
  const omega = Math.sqrt(stiffness / mass);
  const zeta = damping / (2 * Math.sqrt(stiffness * mass));
  if (zeta >= 1) {
    return 1 - (1 + omega * elapsed) * Math.exp(-omega * elapsed);
  }
  const wd = omega * Math.sqrt(1 - zeta * zeta);
  return (
    1 -
    Math.exp(-zeta * omega * elapsed) *
      (Math.cos(wd * elapsed) + (zeta / Math.sqrt(1 - zeta * zeta)) * Math.sin(wd * elapsed))
  );
}

// 3. 带 0.12s 反向微蹲蓄力的弹射进度（先退 -0.08，再按弹簧冲向 1.0）
export function springWithAnticipation(elapsed, crouchDur = 0.12) {
  if (elapsed <= 0) return 0;
  if (elapsed < crouchDur) {
    const p = elapsed / crouchDur;
    return -0.08 * (1 - Math.pow(1 - p, 3));
  }
  const s = springAt(elapsed - crouchDur, { stiffness: 320, damping: 16 });
  return -0.08 + 1.08 * s;
}
```

## 二、从一篇文稿到高清成片：不返工的五步实操流程

真正用 **MotionHarness** 开拍一条 `1.5 – 2 分钟` 的视频时，千万不要把稿子一丢就让 AI 直接写完整支视频的代码。严格按下面 **5 个台阶** 走，最快半小时就能稳稳拿下一条精品：

:::diagram-video-standard-sop:::

### 第 1 步：花 3 分钟填一张「四句话底稿」
开工前自己先把这四行字想清楚：
1. **开头第一句怎么戳痛点？**（前 3 秒留人句）
2. **全片核心哪 3 个观点，有没有一线真实细节？**（把最狠的第 3 点留到压轴）
3. **这期打算用哪 1 个核心图形变形串起全片？**（比如一根红条 `1`、一把尺子或一枚印章）
4. **选哪一套 `DESIGN.md` 皮肤？**（比如商业拆解直接选 `03 · Vox 暖纸社论风`）

### 第 2 步：先让 AI 输出《单焦点分镜表》，人在表里改（不写一行代码！）
让 AI 先把口播拆成一句一镜的表格。你只需要花 5 分钟扫一眼表格里的两列：
- **查「屏幕唯一大字」列**：哪一行超过了 10 个字？哪一行在抄配音原话？当场让它砍成 4 个字的大词！
- **查「画面与动画编号」列**：有没有出现“左右并列两个文本框”？有的话直接查我们的《动画字典》改成 `05 放大看微信细节` 或 `10 传送带激光拦截`。
- *为什么这一步最值钱？因为在表格里改 5 处不满意的地方只要 30 秒；等写成上千行代码再改就要半小时。*

### 第 3 步：关键阀门 —— 只写「前 15 秒小样」并在浏览器里审片！
分镜表确认满意后，命令 AI **只把前 `00:00 ~ 00:15` 秒写成代码**（并配好前 15 秒的语音和去气口时间轴），然后在终端打开 MotionHarness 本地演播厅实时预览：

```bash
# 在浏览器打开 MotionHarness Studio 预览台，随时拖进度条看每一帧
mh open --browser
```

看着跑起来的这 15 秒真实画面，重点盯 4 件事：
1. **手机尺寸缩小时，大字够不够醒目、震撼？**（嫌小就让它把一级字号从 `160px` 提到 `196px`）
2. **留白够不够通透？**（有没有多余的英文角标或细碎边框？有就当场删净）
3. **配音换气紧不紧？**（句与句之间死气沉沉的空白要切掉，金句砸下后留足 `0.5 秒` 音效回响）
4. **弹簧蓄力脆不脆？**

只要这 15 秒调到了让你眼前一亮的 95 分水准，**整支片子的视觉标尺和公共代码函数就彻底锁死了！**

### 第 4 步：抽出公共积木，一口气铺满全片 + 局部打标精修
让 AI 把前 15 秒里验证好的配色常量、大字标题积木、卡片积木放进公共文件 `src/primitives.js`，严格照着同一个质感把剩下的分镜全部写完。
全片连起来看一遍后，如果觉得第 `48 秒` 那枚印章稍微歪了一点，或者某句想换个颜色，直接在预览时间轴上打标指出秒数，让 AI **只定点修改那一幕的函数**，其他满意的段落纹丝不动。

### 第 5 步：抽帧检查遮挡 → 导出 60 帧高清 `.mp4` → 存下好积木
正式导出长视频前，先用快速抽帧命令截几张关键秒数的静态图，一眼扫过有没有文字跑出边界或压到字幕区：

```bash
# 1. 快速抽拍几个关键时间点，确认零遮挡、零错位
mh preview --times 1.2,4.5,12.0,28.5,55.0

# 2. 确认无误后，正式并发抓拍合成 1080p 60fps 高清成片
mh render
```

导出成片后，顺手把这期新做出来的漂亮零件（比如模拟微信窗口、滚动里程表、激光传送带）单独存好。做第 1 期你是在搭台子，做到第 5 期时，你手里就已经攒下了一套别人根本抄不走的私人动态视觉库。

## 三、开工直接复制的「两步标准提示词」

把第二层的 `DESIGN.md` 和 `MOTION.md` 放进你的视频项目文件夹后，直接复制下面这段话发给 AI，填上你的选题就能稳稳开拍：

```text
我们要用 MotionHarness 制作一支 1920x1080、60fps 的视频。请先完整阅读项目根目录下的 DESIGN.md 与 MOTION.md，严格遵守单焦点留白（>=65%）、三级放大字号、75:18:7 配色比例与 prepareFrame(time) 纯时间确定性规则，严禁写成左右并列塞满小字的网页看板。

请严格按下面两步推进，在我确认第 1 步之前不要写任何代码：

【第 1 步 · 现在执行：输出单焦点分镜表】
请根据我下面提供的主题和素材：
1) 先帮我构思 1 个能贯穿全片、在不同章节连续变形的简单几何图形（说明它在各章分别变成什么）；
2) 优化口播逐字稿（把书面套话改成干脆的大白话短句，在核心金句后标出 [留白0.5s]）；
3) 输出完整的《分镜表》，包含四列：镜号与预计秒数 ｜ 口播台词 ｜ 屏幕唯一焦点大字（强制 <=10 个字，绝不重复长句） ｜ 具体画面动作与镜头运动方式（拒绝并列文本框，抽象概念请画成直观物理动作或简化的真实软件界面）。

【第 2 步 · 等我确认分镜表后再执行：先做前 15 秒小样】
等我拍板分镜表后，先不要写整支长片！请只编写并跑通前 15 秒（00:00 ~ 00:15），抽帧自检无遮挡后打开预览供我确认字号张力、留白与弹簧手感；等前 15 秒完全确认满意后，再抽成复用组件把全片铺完。

我这期的视频主题、核心观点与真实案例细节如下：
[在这里粘贴你的想法、草稿或真实案例]
```
